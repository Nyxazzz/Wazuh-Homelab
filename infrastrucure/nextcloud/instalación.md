# INSTALACIÓN Y DESPLIEGUE DE NEXTCLOUD
La instralación y despliegue de Nextcloud se encuentra documentada en un repositorio independiente

**Nextcloud-Deployment**: https://github.com/Nyxazzz/nextcloud-deployment

Este repositorio contiene:

- Despliegue mediante Docker Compose
- Configuración de Nextcloud
- MariaDB
- Volumenes persistentes
- Red Docker
- Puesta en funcionamiento
- Resolución de problemas

Una vez desplegado Nextcloud, se recomienda continuar con la guia de hardening disponible en **configuracion.md**
